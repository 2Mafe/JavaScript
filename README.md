# JavaScript - Interactive System
Implement a functional JavaScript program that allows you to interact with the user, validating input and displaying dynamic responses through the use of basic language functions.

## General Info
The program focuses on user interaction. This means that the program displays messages to the user, requests data, validates that data, and then displays results based on the user's input. JavaScript is used for this purpose.

## Technologies
* JavaScript

## Steps
* Prompt the user for their name and age.
* Validate that the entered age is a valid number.
* Display a personalized message depending on the entered age.
* If the user is under 18, encourage them to continue learning.
* If the user is 18 or older, motivate them to explore new opportunities.
* Display an error if the user enters a non-numeric value for age.
